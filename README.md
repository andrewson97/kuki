# KUKI Cafe Website

Static landing site for KUKI Cafe — served via GitHub Pages.

## Live
Once GitHub Pages is enabled, the site is at:
`https://<your-github-username>.github.io/<repo-name>/`

## Edit
- `index.html` — content
- `style.css` — styling
- `assets/` — logo and images

Push to `main` and GitHub Pages rebuilds automatically.
